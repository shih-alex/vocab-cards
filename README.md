# 單字卡

簡單好用的英文單字卡 App：介面乾淨、手機好用，**把文字檔丟進去就變成字卡**。翻字卡背單字，再用**選擇題**和**拼字題**考考自己。

- 不用註冊、不用網路、沒有廣告，資料只存在你自己的瀏覽器裡。
- 手機、平板、電腦都能用，可以「加入主畫面」當成 App，離線也能背。
- 支援發音朗讀、深色模式、匯出備份。

---

## 怎麼用

### 1. 匯入單字

第一次使用時按首頁的「**匯入文字檔**」或「**貼上文字**」（已經有牌組時，是首頁下方的「**＋ 匯入單字**」）：

- **選擇文字檔**（可一次選多個），或把內容貼到「或直接貼上文字」的框框。
- 下方會即時預覽：可以匯入幾張、有幾張牌組裡已經有了、哪幾行看不懂（附行號和原因）。
- 確認沒問題後按「**匯入 N 張**」。只匯入一個牌組時，匯入完會直接打開那個牌組。
- 在空的牌組裡按「匯入單字到這個牌組」，沒有 `#deck:` 的單字就會直接加進這個牌組。

第一次使用也可以按「**載入範例牌組**」，先用 40 個高中常用單字試試看。

文字檔格式很簡單，一行一張卡：

```text
#deck: 高中英文 Level 4
abandon | /əˈbændən/ | v. 拋棄；放棄 | Someone abandoned the puppy on the side of the road. | 有人把那隻小狗丟在路邊。
absent | adj. 缺席的
```

完整規則（多牌組、Excel / Quizlet / Anki 匯入、例句怎麼寫才能出拼字題、常見錯誤）請看 **[格式說明.md](格式說明.md)**。

### 2. 點牌組

在首頁點一下牌組，會看到三個大按鈕：

| 按鈕 | 做什麼 |
| --- | --- |
| **字卡** | 翻面背單字 |
| **選擇題** | 看英文，選出中文意思 |
| **拼字題** | 看例句，拼出單字 |

- 「**每次測驗題數**」可以選 10、20 或全部（牌組只有 10 個字以內時就是全部）。每次測驗都會重新隨機出題。
- 「**瀏覽與編輯單字**」可以搜尋、新增、修改、刪除單字。
- 右上角的調整按鈕是「牌組設定」：改名稱、選「字卡正面」要顯示英文還是中文、匯出文字檔、刪除牌組（首頁牌組旁的「⋯」也找得到這些功能）。
- 首頁和牌組頁會顯示上次測驗的成績，例如「選擇 8/10 · 拼字 6/10」。

### 3. 字卡

1. 看英文單字，先在心裡想中文意思（可以按 🔊 聽發音）。
2. 點卡片或「**翻面**」，看意思、例句和翻譯；再點一次翻回正面。
3. 按「**下一張 ›**」換下一張（「‹ 上一張」回到上一張），也可以在卡片上**左右滑動**。

- 上方的隨機排序按鈕可以打亂順序（打開時按鈕會變成淡紅色），再按一次恢復原本的順序；不小心按到的話馬上再按一次，會回到原本看到的那張。新增或刪除單字時，順序和你看到的位置都會保留。
- App 會記住你看到第幾張，下次從那裡繼續（牌組頁會顯示「看到第 12 張」）。
- 看完最後一張會出現「看完了！」，可以從頭再看一次，或直接去做選擇題、拼字題。
- 想練「看中文想英文」：牌組設定 →「字卡正面」選「中文」。
- 卡片內容打錯，按上方的 ✎ 就能直接修改。

### 4. 選擇題

- 看英文單字（可以按 🔊 聽發音），從 4 個中文意思裡選出正確的。
- 答對會自動跳到下一題（點一下畫面可以馬上跳過）；答錯會標出正確答案，下面附上例句，看完再按「**下一題**」。新題目剛出現的一瞬間點到的選項不算（那是要跳過上一題的點擊）。
- 選項是從同一個牌組的其他單字挑的；牌組裡的意思不到 4 種時，會借用其他牌組的單字當選項。意思相同（只差詞性或標點）的不會同時出現，跟答案有共同意思的（例如「虔誠、奉獻」和「奉獻、投入」）也盡量不放在一起。
- 中文意思裡的英文補充（`→ Lantern Festival`、`（kneel down）` 這種）在選項裡會先拿掉，免得一看就知道答案；答完後的說明和成績頁還是完整的意思（見 [格式說明.md](格式說明.md) 的「測驗時的中文意思」）。

### 5. 拼字題

- 畫面上是一句例句，單字被挖空、只留頭尾的字母，例如 `Someone a _ _ _ _ _ _ _ d the puppy on the side of the road.`，下面有中文翻譯當提示。
- 在框框裡輸入**完整的單字**（例句裡是 abandoned 就拼 abandoned），按「**確認**」。不分大小寫；單字（不是片語）只打中間缺的字母也算對。be 開頭的片語只考後面的部分（be aware of → aware of，打 be aware of 也算對）。
- 想不起來就按例句卡片右下的「**不會，看答案**」（在輸入框上面，手機鍵盤打開時也看得到）。答錯時例句卡片裡會顯示單字和中文意思，下面再列出正確答案和你的答案；如果只是形態不對（例句要 perceived，你打 perceive），會告訴你「單字拼對了」，不過還是算錯。
- 答錯後馬上再按一次（同一個位置的「下一題」或 Enter）不會跳走，讓你先看清楚正確答案。
- 同一句裡單字出現好幾次時，其他地方也會遮起來。
- 只有例句裡找得到這個單字的卡片才會出題，所以牌組頁有時會顯示「可出 N 題」；「瀏覽與編輯單字」裡會標出「不考拼字」的單字，編輯時例句欄下面也會即時顯示拼字題會怎麼考。例句要怎麼寫，請看 [格式說明.md](格式說明.md) 的「例句和拼字題」。
- 牌組裡一半以上的單字沒有例句時，牌組頁會出現「**請 Claude 幫這個牌組補例句**」：按「複製給 Claude」貼給 Claude，再按「貼上 Claude 的回覆」把回覆貼進來，用「更新內容（保留測驗紀錄）」匯入就有例句了。

### 6. 看成績

- 做完會顯示分數，下面列出「答錯的單字」。
- 「**重測答錯的 N 題**」只重考答錯的題目；「**再測一次**」換一組新題目。
- 測驗做到一半想離開，按左上角的 ✕（選「結束」，這次的成績就不保存）。用手機的返回鍵或手勢離開的話，回到牌組頁點同一個測驗（會顯示「繼續第 N 題」）可以接著做。
- 每一題答對、答錯都會記下來：在「瀏覽與編輯單字」裡，答錯過的單字會標上「錯 N」，點開還能看到答對、答錯各幾次。

### 電腦快捷鍵

| 畫面 | 按鍵 |
| --- | --- |
| 字卡 | `←`／`→` 上一張／下一張、`空白鍵`／`Enter` 翻面、`S` 朗讀 |
| 選擇題 | `1`～`4` 選答案、`Enter` 下一題 |
| 拼字題 | `Enter` 確認答案／下一題 |

設定（首頁右上角 ⚙）裡打開「自動朗讀」，字卡和選擇題出現英文時就會自動唸出來。

## 放到手機上

### 方法 A：免費架站 ＋ 加入主畫面（推薦）

把整個資料夾放到免費的網站空間，就能用手機打開，加入主畫面後**像 App 一樣使用，而且可以離線**。

需要上傳的檔案：`index.html`、`style.css`、`core.js`、`sample.js`、`app.js`、`sw.js`、`manifest.webmanifest`、`icons` 資料夾（其他檔案可傳可不傳）。

- **GitHub Pages**：在 GitHub 建立一個新的 repository（免費帳號要選 **Public**）→ 「uploading an existing file」把上面的檔案拖進去 → Commit → 到 Settings → Pages，Source 選「Deploy from a branch」、Branch 選 `main`、資料夾選 `/ (root)` → 儲存。等一兩分鐘就會得到網址 `https://你的帳號.github.io/repository名稱/`。
- **Netlify Drop**：先免費註冊並登入 Netlify，再打開 <https://app.netlify.com/drop>，把整個 `vocab_cards` 資料夾拖進去，馬上得到一個網址。⚠️ 沒登入就拖進去的網址大約一小時後就會被刪除，加到主畫面的 App 也會跟著打不開。

用手機打開網址後：

- **iPhone（Safari）**：點下方的「分享」按鈕（iOS 26 預設的版面要先點右下角的「⋯」）→「加入主畫面」。⚠️ 主畫面的 App 和 Safari 是**兩份分開的資料**：如果已經在 Safari 裡匯入過單字，請先在 Safari「設定 → 匯出備份」，再打開主畫面的 App「還原備份」。建議一開始就加入主畫面再使用。
- **Android（Chrome）**：點右上角「⋮」→「安裝應用程式」（或「加到主畫面」）。

之後更新了檔案、重新上傳後，App 會在背景下載新版，**下次打開**就會是新版本（一直開著放在背景的主畫面 App，回到前景時也會檢查有沒有新版）。

### 方法 B：同一個 Wi-Fi 下測試

電腦和手機連同一個 Wi-Fi，在 `vocab_cards` 資料夾裡開命令提示字元，執行：

```text
python -m http.server 8000
```

用 `ipconfig` 查電腦的「IPv4 位址」（例如 `192.168.1.23`），手機瀏覽器打開 `http://192.168.1.23:8000`。如果 Windows 防火牆跳出詢問，請允許「私人網路」。

這個方法適合快速測試；因為不是 https，**無法離線使用，也不能安裝成 App**。

### 方法 C：單一檔案版

執行 `python build.py`，會產生 `dist/單字卡.html`，所有東西都包在這一個檔案裡，雙擊就能用（電腦上直接開 `index.html` 也可以）。

適合放在電腦上用或當作備用。手機上能不能直接開啟本機的 HTML 檔要看瀏覽器（例如 iPhone 的「檔案」App 只能預覽、無法使用），手機請優先用方法 A。

## 資料與備份（重要）

- 單字、測驗紀錄和設定存在**這個瀏覽器**裡。換手機、換瀏覽器、清除瀏覽資料，資料就會不見；不同網址（例如方法 A 和方法 B）的資料也是分開的。
- 請**定期備份**：設定 →「匯出備份」，會下載一個 `.json` 檔；需要時用「還原備份」就能完整恢復（會取代目前所有資料）。舊版（1.x）匯出的備份也能還原。
- 想搬家到新手機：舊手機匯出備份 → 傳到新手機 → 新手機「還原備份」。
- **iPhone 特別注意**：Safari 如果大約一週沒打開這個網站，資料可能被系統自動清掉；加入主畫面的 App 不會這樣，但它和 Safari 是兩份分開的資料（不會自動帶過去，要用「匯出備份 → 還原備份」搬）。App 在 iPhone 的 Safari 裡會提醒一次。
- 設定的「匯出備份」下面會顯示上次備份的日期；超過 50 張卡又兩週沒備份時，首頁會提醒你。
- 只想分享某個牌組：牌組「⋯ → 匯出文字檔」，對方用「匯入單字」就能加進去（不含測驗紀錄）。

## 請 Claude 幫你做單字檔

在 App 裡打開匯入畫面（首頁沒有牌組時，也可以按「沒有單字檔？請 Claude 幫你做」），在「還沒有單字檔？請 Claude 幫你做」那一格按 **「複製給 Claude 的說明」**。把複製到的內容貼給 Claude，填上主題和牌組名稱（例如「學測 Level 4 單字 30 個」「Level 4 第 1 回」）就可以了。同一段說明也在 [格式說明.md](格式說明.md) 最後一節。

說明裡已經請 Claude 讓每個例句都包含這個單字本身或它的規則變化（不用 took、bought 這種不規則變化，也不把片語拆開），這樣每個單字都能出拼字題。

Claude 給你的內容可以直接複製、貼到匯入畫面的文字框，或存成 `.txt`（UTF-8）後匯入。**整則回覆一起複製也沒關係**：只要單字在程式碼框（```）裡，就只會匯入框裡的內容，前後的說明文字會略過。就算它回了 Markdown 表格或編號清單，App 也大多看得懂。

## 給開發者

純 HTML / CSS / JavaScript，沒有任何框架或建置工具，直接開 `index.html` 就能執行。

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`style.css`、`app.js` | 介面 |
| `core.js` | 純邏輯（不碰 DOM）：文字檔解析／匯出、例句裡找單字與挖空、拼字比對、測驗出題 |
| `sample.js` | 範例牌組（由 `tools/gen_sample_js.py` 從 `samples/` 產生，請勿手動修改） |
| `sw.js`、`manifest.webmanifest`、`icons/` | 離線快取與「加入主畫面」 |
| `build.py` | 打包成單一檔案 `dist/單字卡.html` |
| `_config.yml` | GitHub Pages 設定：不把 `tests/`、`tools/` 等開發用檔案放到網站上 |
| `tools/gen_icons.py` | 重新產生圖示（需要 Pillow、fontTools） |
| `tests/` | 測試：`core.test.html`（邏輯）、`e2e.html`（實際操作整個 App）、`shot.html` + `shots.py`（各畫面截圖） |
| `格式說明.md` | 匯入文字檔的格式規格 |

常用指令（在 `vocab_cards` 資料夾執行）：

```text
python tools/gen_sample_js.py           # 修改 samples/ 的範例檔後，重新產生 sample.js
python tools/gen_icons.py               # 重新產生 icons/
python build.py                         # 產生 dist/單字卡.html
python tests/run_tests.py               # 用無頭 Edge 執行全部測試（請在 PowerShell 或命令提示字元執行，Git Bash 不行）
python tests/run_tests.py e2e.html      # 只執行指定的測試頁
python tests/shots.py                   # 產生各畫面截圖到 tests/shots/（同上，需在 PowerShell 執行；--list 列出所有畫面）
```

- 也可以在自己電腦上用瀏覽器打開 `http://localhost:8000/tests/e2e.html`（先在 `vocab_cards` 執行 `python -m http.server 8000`）觀看測試過程。**只能在 localhost／127.0.0.1 執行**：測試頁和 App 在同一個網址底下會共用 `localStorage`，所以測試頁在其他網址會拒絕執行；`_config.yml` 也讓 GitHub Pages 不發布 `tests/`、`tools/`。
- 資料存在 `localStorage` 的 `vocabcards.v1`（資料格式 `version: 2`；舊的 version 1 資料和備份在載入、還原時會自動轉換）；網址加上 `?sk=其他名稱` 可以使用另一份獨立的資料（測試用）。
- **每次發布新版**：`core.js` 的 `VC.version`、`app.js` 的 `APP_VERSION`、`sw.js` 的 `VERSION` 改成同一個新版本號，並把 `sw.js` 的 `CACHE` 加一（例如 `vocabcards-v5` → `vocabcards-v6`）。`sw.js` 有變，瀏覽器才會安裝新的 Service Worker，把所有檔案一次換成新版；`tests/e2e.html` 會檢查三個版本號一致。萬一還是遇到新舊檔案混在一起，App 一啟動發現 `core.js` 和 `app.js` 版本不一致，會清掉快取重新載入。
- 「複製給 Claude 的說明」（`app.js` 的 `CLAUDE_PROMPT`）要和 `格式說明.md` 第 11 節一字不差，`tests/e2e.html` 會檢查。
